# ETIS Bot

Telegram-бот для быстрого доступа к разделам электронной
информационной системы ПГНИУ.

Разработан как самостоятельный студенческий проект.
Проект был представлен руководству электронной образовательной среды.

## Возможности

- Открытие расписания, оценок, учебного плана и списка преподавателей.
- Открытие страниц ЕТИС внутри Telegram через Web Apps.
- Сохранение последнего выбранного раздела между перезапусками.
- Статистика пользователей и обращений к функциям бота.
- Команды администратора для просмотра и очистки статистики.

Бот открывает существующие страницы ЕТИС. Авторизация
в системе выполняется на стороне сайта университета.

## Технологии

Python 3.13, aiogram 3, asyncio, python-dotenv, JSON.

## Установка и запуск

Команды для macOS / Linux. Требуется Python 3.13.

В папке проекта создайте и активируйте виртуальное окружение:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Создайте локальный файл настроек:

```bash
cp .env.example .env
```

Заполните `.env`:

- `BOT_TOKEN` — токен Telegram-бота, полученный у BotFather.
- `ADMIN_ID` — числовой Telegram ID администратора.
  Значение `0` оставляет административные команды недоступными.

Запустите бота:

```bash
python main.py
```

## Команды

| Команда | Назначение |
| --- | --- |
| `/start` | Открыть меню |
| `/help` | Получить справку |
| `/last` | Открыть последний сохранённый раздел |
| `/stats` | Посмотреть статистику — только администратор |
| `/clearstats` | Очистить статистику — только администратор |

## Хранение данных

Последние выбранные разделы сохраняются в `last_url.json`,
статистика — в `stats.json`. Эти файлы создаются автоматически.

Локальные настройки, данные пользователей и виртуальное
окружение исключены из Git через `.gitignore`.

## Ограничения

Ссылки и кнопки оценок настроены на конкретные триместры.
При изменении структуры ЕТИС их потребуется обновить.

Это неофициальный студенческий проект.
